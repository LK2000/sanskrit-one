Vibhakti tables for ऊकारान्त स्त्रीलिङ्गम्

वधू Bride
विभक्तिःएकवचनम्द्विवचनम्बहुवचनम्
प्रथमावधूःवध्वौवध्वः
द्वितीयावधूम्वध्वौवधूः
तृतीयावध्वावधूभ्याम्वधूभिः
चतुर्थीवध्वै / वधवेवधूभ्याम्वधूभ्यः
पञ्चमीवध्वाः / वधोःवधूभ्याम्वधूभ्यः
षष्ठीवध्वाः / वधोःवध्वोःवधूनाम्
सप्तमीवध्वाम् / वधौवध्वोःवधूषु
सम्बोधनहे वधुहे वध्वौहे वध्वः

भ्रूः Eyebrow
विभक्तिःएकवचनम्द्विवचनम्बहुवचनम्
प्रथमाभ्रूःभ्रुवौभ्रुवः
द्वितीयाभ्रुवम्भ्रुवौभ्रुवः
तृतीयाभ्रुवाभ्रूभ्याम्भ्रूभिः
चतुर्थीभ्रुवै / भ्रुवेभ्रूभ्याम्भ्रूभ्यः
पञ्चमीभ्रुवाः / भ्रुवःभ्रूभ्याम्भ्रूभ्यः
षष्ठीभ्रुवाः / भ्रुवःभ्रुवोःभ्रूणाम् / भ्रुवाम्
सप्तमीभ्रुवाम् / भ्रुविभ्रुवोःभ्रूषु
सम्बोधनहे भ्रूःहे भ्रुवौहे भ्रुवः

श्वश्रूः Sister-in-law
विभक्तिःएकवचनम्द्विवचनम्बहुवचनम्
प्रथमाश्वश्रूःश्वश्र्वौश्वश्र्वः
द्वितीयाश्वश्रूम्श्वश्र्वौश्वश्रूः
तृतीयाश्वश्र्वाश्वश्रूभ्याम्श्वश्रूभिः
चतुर्थीश्वश्र्वै / श्वश्र्वेश्वश्रूभ्याम्श्वश्रूभ्यः
पञ्चमीश्वश्र्वाः / श्वश्र्वःश्वश्रूभ्याम्श्वश्रूभ्यः
षष्ठीश्वश्र्वाः / श्वश्र्वःश्वश्र्वोःश्वश्रूणाम्
सप्तमीश्वश्र्वाम् / श्वश्र्विश्वश्र्वोःश्वश्रूषु
सम्बोधनहे श्वश्रूःहे श्वश्र्वौहे श्वश्र्वः

जम्बूः Tree
विभक्तिःएकवचनम्द्विवचनम्बहुवचनम्
प्रथमाजम्बूःजम्ब्वौजम्ब्वः
द्वितीयाजम्बूम्जम्ब्वौजम्बूः
तृतीयाजम्ब्वाजम्बूभ्याम्जम्बूभिः
चतुर्थीजम्ब्वै / जम्बवेजम्बूभ्याम्जम्बूभ्यः
पञ्चमीजम्ब्वाः / जम्बोःजम्बूभ्याम्जम्बूभ्यः
षष्ठीजम्ब्वाः / जम्बोःजम्ब्वोःजम्बूनाम्
सप्तमीजम्ब्वाम् / जम्बौजम्ब्वोःजम्बूषु
सम्बोधनहे जम्बुहे जम्ब्वौहे जम्ब्वः

प्रथमाभूःभुवौभुवः

पञ्चमीभुवाः / भुवःभूभ्याम्भूभ्यः
षष्ठीभुवाः / भुवःभुवोःभूनाम् / भुवाम्
सप्तमीभुवाम् / भुविभुवोःभूषु
